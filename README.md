# 图片剪裁器

双击 `index.html` 即可使用，无需安装。纯浏览器端运行，离线可用。

## 功能

- **裁剪模式** — 拖拽创建裁剪框，支持自由比例 / 1:1 / 4:3 / 3:2 / 16:9 / 9:16 / 自定义比例
- **缩放模式** — 指定像素尺寸输出，实时预览，支持保持宽高比
- **精确调整** — 裁剪框八角拖拽手柄、九宫格辅助线
- **高清渲染** — 适配高分屏，输出不模糊
- **撤销重做** — Ctrl+Z / Ctrl+Y，最多 50 步历史
- **深色主题** — 工具栏一键切换，跟随系统偏好

## 快捷键

| 按键 | 功能 |
|------|------|
| `滚轮` | 缩放图片 |
| `拖拽图片外` | 平移视角 |
| `Space + 拖拽` | 平移视角（备用手势） |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Y` | 重做 |
| `Ctrl + 0` | 重置缩放 |
| `Enter` | 保存 |
| `Esc` | 重置裁剪 + 缩放归位 |
| `Delete` | 清除裁剪框 |

## 使用方式

1. 双击 `index.html`（Edge / Chrome 均可）
2. 点击「打开图片」选择照片
3. 裁剪或缩放模式调整参数
4. 点击「保存结果」，弹出另存为对话框
5. 保存到任意位置，文件名自动加上「-修改后」后缀

## 技术

纯 HTML + CSS + JavaScript，无框架、无构建工具、无外部依赖。基于 Canvas 2D API 和 File System Access API。
